## [0.3.0] - 2026-09-21

### Added

- 文档视图缩放（Word 状态栏样式）：状态栏右下角「− 滑块 百分比 +」，
  点击百分比复位 100%；作用于 Markdown 可视化/源码编辑器（50%–250%）、
  PDF 阅读（40%–400%）、图片查看（25%–500%）、Office 快速预览（50%–250%）；
  PDF 工具栏缩放按钮与状态栏共享同一缩放状态。
- 目录树文件操作（§6.3）：右键菜单支持新建文档 / 新建文件夹 / 重命名 /
  移动到… / 删除（进系统回收站可还原）；同级同名冲突、目录移动进自身、
  文件被占用等场景明确报错；名称合法性校验（路径分隔符 / 连续点号 /
  隐藏前缀 / Windows 保留名）；树头部与工具栏「新建文档 / 新建文件夹」接线。

### Fixed

- 目录树中无法打开文件——双击文件现在按格式路由（编辑器 / PDF 阅读器 /
  Office 预览 / 图片查看），与文件列表行为一致；
- 编辑器或查看器打开时，左侧活动栏（开始 / 搜索 / 任务等）点击无效——
  现在统一走视图切换入口，编辑器与查看器自动收起；
- 同类遮挡问题：标题栏切换文档库、删除当前库、搜索结果点击聚焦、
  交付中心打开等场景下编辑器 / 查看器状态残留，现已互斥关闭；
- 编辑器存在未保存修改时，切换视图弹出离开确认，防误丢修改。

## [0.2.0] - 2026-09-21

### Added

- Tauri 2 + React 19 + TypeScript + Vite + Tailwind CSS 4 工程骨架；
  应用外壳：无边框窗口、自定义标题栏（库切换）、活动栏导航、状态栏。
- 文档库核心：建库向导（三步）、目录树（懒加载）、文件列表、详情面板、
  格式注册表（17 类）、SQLite 索引库、目录扫描（排除规则、上限保护、后台事件）、
  标题栏库切换菜单与最近文档库。
- 文件监听与自动重索引：notify 递归监听、1.2 秒防抖全量重扫、
  被占用文件跳过不中断扫描。
- 全文检索与搜索视图：文本类格式正文提取 + FTS5 trigram（支持中文子串）、
  命中片段高亮、结果定位跳转、Ctrl+K。
- 后台任务中心：进度、取消、完成摘要、失败原因与历史清理。
- 原生编辑闭环：Markdown 可视化画布（Tiptap）+ 源码模式（CodeMirror 6）、
  原子保存、外部修改冲突检测（覆盖 / 重新载入 / 取消）、
  历史快照与一键恢复（每文件 20 个版本）。
- PDF 阅读与 Office 快速预览：PDF.js 渲染 / 翻页 / 缩放 / 跨页文本搜索；
  DOCX / XLSX / PPTX OOXML 安全提取（正文可检索）；系统应用打开。
- 转换与导入：组件管理器（Pandoc / LibreOffice / Edge 探测）、
  DOCX → Markdown 可编辑副本（转换预检：加密阻断、宏 / 修订 / 批注提示）、
  DOCX / HTML 导入、可选 LibreOffice 高保真预览。
- AI 工作台：OpenAI 兼容 Provider（API Key 存 Windows 凭据库）、
  连通性测试分类、上下文门禁与敏感信息扫描、流式引用问答、
  AI 润色行级差异审阅、结果存为文档、文档质量检查（标题层级 / 断链 /
  空章节 / 敏感信息）。
- Windows OCR 与批注：图片文字识别入全文索引、图片查看器、
  引用选中文本批注（解决 / 重开 / 删除 / 位置重定位检测）。
- 正式交付中心：质量门禁预检、来源 SHA-256 冻结、
  Markdown / HTML / DOCX / PDF / ZIP 五格式管线、产物验证与原子落盘、
  交付清单与交付历史。
- 仓库标准文件与产品设计文档（docs/产品设计/）；
  测试文档库基线（D:\MarkFlow，24+ 个多格式文件）。

### Verification

- Rust 单元 / 集成测试 31 项（格式识别、扫描排除、检索往返、任务生命周期、
  Office 提取、编辑冲突与历史、交付门禁管线等），零警告；
- 5 万混合文件库性能 Spike：扫描 + 提取 + 索引约 9,092 文件/秒，
  中文全文检索 30ms（命中 5,000），文件名检索 0.27ms。
