# MarkFlow 使用指南

> 文档日期：2026-09-21
> 文档版本：v1.0
> 适用版本：MarkFlow v0.3.0 及以上
> 适用平台：Windows 10/11 x64

---

## 1. 快速理解 MarkFlow

MarkFlow 把一个普通的本地文件夹变成「文档库」：库里的 Markdown、Word、PDF、Excel、PPT、图片、代码等所有文件都可以被搜索、预览、编辑、批注和正式交付。

**三条使用底线**（也是产品承诺）：

1. 文件永远保存在原位置——MarkFlow 不移动、不复制、不修改你的文件（除非你主动编辑保存）；
2. 所有处理本地完成——不联网上传，无需登录；
3. 索引可随时重建——SQLite 数据库只是索引缓存，删除后重扫即可恢复，原文永远以文件系统为准。

---

## 2. 创建与打开文档库

### 2.1 创建文档库

1. 启动 MarkFlow，点击「创建文档库」（开始页 / 文档库页 / 标题栏菜单均可入口）。
2. **第一步 · 选择文件夹**：点击「浏览…」选择一个本地文件夹。MarkFlow 会立即统计其中的文件数量与总大小（已按排除规则过滤）。
3. **第二步 · 索引设置**：
   - 全文索引 / 图片 OCR / 便携元数据：三个开关当前仅记录设置，对应能力随版本逐步启用；
   - 排除规则：默认已排除 `.git`、`node_modules`、`target`、`dist`、`__pycache__` 等 12 类目录与所有点号开头的隐藏项；可追加自定义目录名（逗号分隔），失焦后自动重新统计。
4. **第三步 · 确认创建**：核对摘要后点击「创建文档库」。

创建完成后立即开始后台扫描，进度显示在底部状态栏与「任务」中心。

### 2.2 打开 / 切换 / 移除

- 标题栏左侧下拉可查看全部文档库：点击切换、右上角删除按钮「从 MarkFlow 移除索引」（**不删除磁盘文件**）、底部「关闭当前文档库」。
- 「开始」页展示最近文档库列表，按最近打开排序。

> 提示：同一文件夹只允许创建一个文档库；重复创建会提示直接打开。

## 3. 浏览文档库

文档库视图为三栏布局（对应 UI 概念图「多格式文档库主界面」）：

- **左侧**：文档库信息、智能集合（占位，后续迭代）、目录树。
- **中央**：面包屑导航 + 文件列表。点击列头可按名称 / 修改时间 / 大小排序（目录始终在前）；单击选中查看详情；双击目录进入、双击文件打开。
- **右侧**：详情面板——类型、大小、修改时间、完整磁盘位置。

### 3.1 目录树操作

在目录树节点上**右键**打开菜单：

| 菜单项 | 说明 |
|---|---|
| 新建文档 / 新建文件夹 | 仅文件夹节点显示；在所选目录下创建 |
| 重命名 | 同级重名校验，不允许改为已存在的名称 |
| 移动到… | 从目录列表中选择目标位置；不能移动进自身或其子目录 |
| 删除（进回收站） | 二次确认后移入系统回收站，可从回收站还原 |

规则与保护：

- 名称不允许包含 `/`、`\`、连续点号，不允许以点号开头，不允许 Windows 保留名（con、nul 等）；
- 同级同名文件 / 文件夹已存在时拒绝并提示；
- 文件被其他程序占用时操作失败并给出原因，不做强制删除；
- 所有操作完成后自动重扫，索引、搜索、列表随之更新。

### 3.2 打开文件

除了在文档库中双击，也可以用「文件 → 打开文件…」（`Ctrl + O`）、把文件拖进窗口，或在资源管理器中双击 `.md` / `.markdown` 文件（安装时已注册文件关联）直接打开：

- 文件位于某个已有文档库内 → 自动切换到该库并定位；
- 文件不在任何文档库内 → 进入**单文件模式**：只索引你打开的这个文件（不会扫描所在文件夹），仍可使用编辑、历史快照、批注、AI 等能力；标题栏显示「单文件 · 文件夹名」，该会话不会出现在文档库列表中；
- 「文件 → 最近打开的文件」与「开始」页会列出最近打开的文件。

双击文档库中的文件时，按格式自动路由：

| 格式 | 行为 |
|---|---|
| Markdown | 编辑器（可视化 / 源码双模式） |
| 文本 / 代码 / JSON / YAML / XML / 配置 / CSV | 编辑器（源码模式） |
| PDF | PDF 阅读器 |
| Word / Excel / PowerPoint | Office 快速预览 + 系统应用打开 |
| 图片 | 图片查看器（含 OCR） |
| 其他格式 | 使用系统应用打开（右侧详情） |

## 4. 编辑文档

### 4.1 Markdown 双模式

- **可视化模式**：Word 式分页画布，工具栏提供标题（H1–H3）、加粗、斜体、无序 / 有序 / 任务列表、引用、代码块、插入表格、撤销 / 重做、AI 润色。
- **源码模式**：CodeMirror 6，Markdown / JSON / YAML 语法高亮。
- 顶部按钮随时互切，内容双向同步。Markdown 文件本身是唯一真源——可视化编辑的每一步最终都序列化回 Markdown 保存。

### 4.2 保存与冲突

- **编码与换行符保持不变**：读取时自动识别 UTF-8 / UTF-8 BOM / UTF-16 / GBK，保存时按原编码与原换行符（CRLF / LF）写回，状态栏显示「编码 X」。GBK 文件中若写入 GBK 无法表示的字符（如 emoji）会拒绝保存并提示，不会悄悄损坏文件；既非 UTF-8 也非 GBK 的文件会拒绝编辑，请用系统应用打开。
- **自动保存**：在「设置 → 自动保存」开启后，停止输入 3 秒自动保存（保存前仍会创建历史快照）。
- **草稿恢复**：未保存的编辑会防抖写入本地草稿；应用异常退出或断电后再次打开该文件，会提示「恢复草稿 / 丢弃草稿」。
- **未保存保护**：切换文档库、返回文档库、打开其他文件、退出应用时若有未保存修改，都会弹出确认。
- **外部修改检测**：回到 MarkFlow 窗口时会检查文件是否被外部程序改动——无未保存修改则自动载入最新内容；有未保存修改则顶部提示，由你选择载入外部版本或保留自己的修改。
- **Markdown 可视化保护**：Front Matter（文件头 `---` 元数据）在可视化编辑中原样保留；文档含 HTML、脚注、Wiki 链接、数学公式、Mermaid、Callout 等可视化模式无法无损保留的语法时，默认进入源码模式，手动切换到可视化前会提示风险。

- `Ctrl + S` 或右上「保存」按钮；标题栏实时显示「已保存 / 未保存 / 保存中 / 失败」。
- 保存流程：冲突检测 → 自动快照当前内容 → 临时文件写入 + 刷盘 → 原子替换 → 更新搜索索引。任一步失败都不会破坏原文件。
- **外部冲突**：如果文件在编辑期间被其他程序（如同事通过共享目录、其他编辑器）修改，保存时会提示三选一：**覆盖保存**（以编辑器内容为准）/ **重新载入外部版本**（以磁盘为准）/ **取消**。

### 4.3 历史快照与恢复

- 每次保存前自动创建快照，每个文件保留最近 20 个版本。
- 编辑器「历史」下拉：按文件查看并一键恢复。
- 「历史」视图：按库浏览全部快照（恢复中心）。恢复前当前内容也会先存为新快照，因此任何恢复操作本身都可回退。

### 4.4 缩放

状态栏右下角提供「− 滑块 百分比 +」控件（与 Word 一致）：点击百分比展开**预置档位**（50% / 75% / 100% / 125% / 150% / 200% …，按当前视图允许的范围），双击百分比复位 100%。也可用 `Ctrl + 滚轮`、`Ctrl + +` / `Ctrl + −` / `Ctrl + 0`：

| 视图 | 范围 |
|---|---|
| 可视化 / 源码编辑器 | 50%–250% |
| PDF 阅读 | 40%–400% |
| 图片查看 | 25%–500% |
| Office 快速预览 | 50%–250% |

---

### 4.5 菜单栏与快捷键

标题栏左侧提供「文件 / 编辑 / 查看 / 帮助」菜单：文件（打开文件、最近文件、新建文档库 / 文档、保存、关闭文档库、退出）、编辑（撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选、搜索）、查看（各视图、缩放、全屏）、帮助（快捷键、关于）。

| 快捷键 | 功能 |
|---|---|
| `Ctrl + O` | 打开文件 |
| `Ctrl + N` | 在当前文档库根目录新建文档 |
| `Ctrl + S` | 保存 |
| `Ctrl + K` | 搜索 |
| `Ctrl + +` / `Ctrl + −` / `Ctrl + 0` / `Ctrl + 滚轮` | 放大 / 缩小 / 实际大小 / 缩放 |
| `F11` | 全屏 |

## 5. 全文搜索

- 入口：活动栏「搜索」、标题栏搜索框、快捷键 `Ctrl + K`。
- **≥ 3 个字符**：检索文件名与正文（Markdown / 文本 / 代码 / JSON / YAML / CSV 等，Office 正文已接入），支持中文子串匹配。
- **不足 3 个字符**：仅匹配文件名。
- 结果展示命中片段（关键词以【】高亮）与命中位置标记；点击结果自动跳转到文件所在目录并选中。
- 搜索范围是当前打开的文档库。

---

## 6. PDF 阅读

- 双击 PDF 打开阅读器：**连续滚动**（像 Word 阅读视图），左侧缩略图导航（可收起），页码输入框直接跳转。
- 默认自适应宽度；缩放用状态栏、`Ctrl + 滚轮` 或 `Ctrl + +/−`（50%–300%）。
- 文字可**选中并复制**；**跨页搜索**：输入关键词后列出所有命中页码，命中的文字在页面上高亮，点击页码定位。
- 长文档只渲染视口附近的页面，滚动远离后自动释放，不占内存；文件被外部程序改动后回到窗口会自动刷新。
- 「系统打开」：调用系统默认 PDF 程序。
- 尚未支持：批注、表单填写、扫描版 PDF 的 OCR（见第 9 节）。

## 7. Office 文件

### 7.1 预览：版式预览与文本快速预览

双击 DOCX / XLSX / PPTX（以及 DOC / XLS / PPT、ODT、RTF 等）时：

- **按格式选择默认阅读方式**：

| 格式 | 默认方式 | 首次打开 | 精确模式 |
|---|---|---|---|
| Word | Office 生成的 PDF，连续滚动阅读 | 先显示目录（标题样式提取）和文字，后台生成完成后自动切换；可取消 | Office PDF |
| Excel | 原生表格视图（列宽 / 合并 / 冻结窗格 / 样式 / 数字格式），不转 PDF | 立即显示 | 「打印版式预览」（按页宽缩放的 Office PDF） |
| PowerPoint | 逐页图片：缩略图导航 + 单页大图 | 导出一页显示一页，方向键翻页 | 同左；「文本大纲」可切换 |
| 无 Office（如虚拟机） | Word / PowerPoint 使用**内置渲染**（不依赖任何外部软件）；只有 LibreOffice 时为 PDF 版式预览 | 几乎即时 | — |

  **切换引擎**：在「设置 → Word / PowerPoint 预览引擎」中选择——「内置渲染」为默认（即时显示、有目录导航，不启动 Office，保真度略低）；「自动（有 Office 优先）」则在装有 Office / LibreOffice 时使用它们导出的精确版式（首次需几秒）。无论默认选哪种，Word / PowerPoint 预览工具栏都有「内置渲染 | Office 版式」切换控件（装有 Office / LibreOffice 时显示），可随时只对当前这份文档切换到精确版式或切回内置渲染，不必进设置。Excel 始终使用原生表格。上表的「默认方式」在选择「自动」时适用；默认的内置渲染下 Word / PowerPoint 直接使用内置渲染。

  **内置渲染**：Word 渲染为分页页面（标题样式 / 加粗斜体颜色 / 表格 / 图片 / 页眉页脚 / 脚注，左侧目录可跳转）；PowerPoint 渲染为连续滚动的幻灯片加缩略图导航（文字 / 形状 / 图片 / 表格 / 常见图表，不含动画）。保真度低于 Office 导出的版本：缺字体时用系统字体替代，SmartArt 和 3D 效果只是近似，自动分页与 Word 可能略有出入。旧版 `.doc` / `.xls` / `.ppt` 与加密文件无法在内置渲染中打开，请安装 Office / LibreOffice、另存为新格式，或用系统应用打开。工具栏的「纯文本 / 文本大纲」可切换到提取文字的视图。

  **Excel 筛选**：表格视图顶部的「筛选」按钮开启后，表头行每列出现筛选下拉（搜索 + 值列表 + 全选 / 清除），按值筛选并隐藏不匹配的行，行号保持原样，可「清除全部筛选」；表头行自动识别（文件里的自动筛选范围 → 冻结窗格最后一行 → 第一个有多个单元格的行），也可在「表头行」下拉手动指定。筛选只影响显示，不修改文件。

  版式预览由本机 Microsoft Office 在后台**只读、禁用宏、无界面**地导出，不会修改原文件，也不会弹出 Office 窗口。首次约需几秒；结果按文件缓存（路径 + 修改时间 + 大小），文件修改后自动失效；选中 Word / PowerPoint 文件时会提前在后台预热。若你已经打开了 Word / Excel / PowerPoint，MarkFlow 只会关闭它自己打开的那份文档，不会退出你的应用。用 Word / Excel / PowerPoint 编辑并保存后回到 MarkFlow，预览会自动刷新。
- **文本快速预览**：没有任何版式引擎，或版式预览失败（如文件受密码保护），自动回退到提取文本的快速预览；版式预览界面右上「文本预览 / 转换」也可手动切换（并可在这里「转换为可编辑文档」）。快速预览的内容：

  - DOCX：段落流（仅文字，不含字体与版式）；
  - XLSX：工作表标签 + 网格（前 200 行 × 30 列，最多 8 个工作表）；
  - PPTX：幻灯片大纲（页码 / 标题 / 正文要点）。

提取文本已进入全文索引——Office 内容可以直接被搜索命中。

### 7.2 转换为可编辑文档（DOCX）

1. 打开 DOCX 快速预览，点击「转换为可编辑文档」。
2. **转换预检**：文件加密 / 损坏会被阻断；宏、修订、批注会给出风险提示（知情确认）。
3. 确认后在**源文件同目录**生成同名 `.md` 副本（图片等附件存入同名 `.media` 目录）。
4. 副本自动打开进入编辑器；原 DOCX 保持不变。

需要 Pandoc 组件（未安装时按钮不可用，见第 10 节）。

### 7.3 系统应用打开

所有 Office / PDF / 图片等文件都可以「系统打开」交给本机已装的 Word / Excel / WPS 编辑；
保存后 MarkFlow 的文件监听会自动重新索引，搜索结果随之更新。

可选安装 LibreOffice 后，Office 预览页会出现「高保真预览」按钮（渲染为 PDF 查看版式）。

## 8. AI 工作台

### 8.1 配置 Provider

1. 「设置 → AI Provider」→「添加 Provider」。
2. 填写名称、接口地址（OpenAI 兼容，通常以 `/v1` 结尾）、模型名、API Key。
3. 保存。API Key 存入 **Windows 凭据库**，不写入任何文件，也不回传界面。
4. 「测试连接」会区分：网络错误 / 认证失败 / 地址不存在 / 服务端问题。

### 8.2 上下文门禁

每次发送前，MarkFlow 会组装所选上下文并展示：

- 文件范围（哪些文件、是否被截断、哪些被跳过）；
- 字符总数与 Token 估算（粗略值）；
- **敏感信息扫描结果**（API Key、JWT、私钥、数据库连接串、手机号、身份证等 9 类规则，命中内容脱敏展示）。

扫描命中时必须点击「知情并继续发送」才会真正调用 Provider；否则不会发出任何请求。

### 8.3 对话与引用

- 编辑器「AI 助手」面板：默认以当前文档为上下文，可勾选库内其他文件（单文件 6 万字符 / 总量 20 万字符上限，超出截断并标注）。
- 回答流式输出，引用位置以【来源 n】高亮标注，可点击来源编号对应的文件路径回看。
- 每条回答可「存为文档」：在当前文件同目录生成新的 Markdown 文档，自动进入索引。

### 8.4 AI 润色（差异审阅）

1. 可视化编辑器工具栏点击「AI 润色」。
2. AI 返回润色结果后进入**差异审阅**：红色删除线为移除内容，绿色为新增内容。
3. 「应用修改」写入编辑器（随后的保存会自动快照原内容，可从历史恢复）；「放弃」则不做任何更改。
4. 文档含敏感信息时会先提示确认。

## 9. OCR 与批注

### 9.1 图片 OCR

1. 双击图片打开查看器。
2. 点击「OCR 识别」——使用 Windows 系统识别能力，识别文字自动进入全文索引（之后可以直接搜到图片中的文字）。
3. 识别结果在右侧面板展示，可复制。

> 要求系统安装对应 OCR 语言包（中文 / 英文）。缺失时按提示到 Windows 设置 → 时间和语言 → 语言中添加。
> 当前 Windows SDK 未提供置信度字段，因此界面不显示置信度数值。
> 扫描版 PDF 的页面级 OCR 将在后续版本提供。

### 9.2 批注

1. 在编辑器中**选中一段文本**。
2. 打开「批注」面板：点击引用所选内容，输入批注意见，添加。
3. 批注列表支持标记已解决 / 重新打开 / 删除。
4. 原文修改导致引用无法定位时，批注会标注「位置已变」——内容不会丢失。

## 10. 质量检查

编辑器工具栏「检查」按钮一键运行（Markdown 文件）：

| 级别 | 示例 |
|---|---|
| 错误 | 断链（相对链接目标不存在）、疑似敏感信息 |
| 警告 | 标题层级跳跃（H1 直接接 H3）、空章节 |
| 建议 | 缺少一级标题 |

点击条目定位行号；「重新检查」随时刷新。错误级检查同时是正式交付的门禁条件（见下节）。

---

## 11. 正式交付

「文档库 → 交付」打开交付中心，五步完成正式交付：

1. **来源选择**：勾选要交付的文件。
2. **交付格式**：Markdown 原文 / HTML（Pandoc）/ Word（Pandoc）/ PDF（Pandoc→HTML→Edge 打印）/ ZIP 打包。缺少组件的格式会标注并禁用。
3. **目标目录与预检**：选择输出目录后点「交付预检」——来源逐个计算 SHA-256 冻结，并执行质量门禁与敏感信息扫描；**存在错误项时阻止交付**。
4. **开始交付**：临时目录生成全部产物 → 验证（存在 / 非空 / DOCX 有效性）→ 原子改名落盘到「交付-时间戳」子目录，同时生成含来源哈希的「交付清单.md」。
5. **交付历史**：查看历史记录（状态 / 产物 / 目录 / 失败原因），一键打开产物文件夹。

---

## 12. 后台任务中心

活动栏「任务」查看所有后台任务（扫描、自动重扫、转换、导入、交付）：

- 运行中任务显示已处理条目数，可点击「取消」；
- 已完成任务显示摘要（文件数 / 跳过数）；
- 失败任务显示完整错误信息；
- 「清除已完成」一键清理历史。

任务历史保存在内存中，重启应用后清空。状态栏会显示「N 个任务运行中」，点击直达。

## 13. 数据存储与隐私

| 数据 | 位置 | 说明 |
|---|---|---|
| 你的文档 | 你自己选择的文件夹 | 原格式、原路径，MarkFlow 不改动 |
| 索引数据库 | `%APPDATA%\com.markflow.app\markflow.db` | 可随时删除重建 |
| AI API Key | Windows 凭据库 | 不落文件、不进数据库 |
| 历史快照 / 批注 | 同上数据库 | 文本类文件专用 |

MarkFlow 不包含任何联网上传逻辑；AI 对话仅在你明确确认后才把所选内容发送给你自己配置的 Provider。

## 14. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 安装时 SmartScreen 拦截 | 安装包未签名，选「更多信息 → 仍要运行」 |
| 图片 OCR 提示缺语言包 | Windows 设置 → 时间和语言 → 语言 → 添加中文（简体） |
| 目录树右键「删除」失败 | 文件被占用（如 Excel 打开中），关闭占用程序后重试；或稍后由文件监听自动恢复状态 |
| 保存弹出「外部修改」 | 文件被其他程序改动，按需选择覆盖 / 重新载入 |
| 搜索短词（1–2 字）搜不到正文 | 短词仅匹配文件名；输入 ≥3 字关键词再试 |
| 索引和实际文件不一致 | 触发一次文件变更（或重启应用）自动重扫；必要时可在设置中重建索引 |
| LibreOffice / Pandoc 相关按钮不可用 | 组件未安装，见「设置 → 组件」状态与安装指引 |
